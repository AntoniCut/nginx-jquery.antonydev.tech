Estilo del cursor

El cursor se queda en el centro, respecto al ratón

El cursor está en left -5 y top -5

La posición del cursor solo usa el valor bottom

Coloca el cursor mientras arrastras. Por defecto aparece en el centro del objeto. cursorAt indica otro punto, en píxeles desde top, right, bottom o left. cursor cambia el aspecto con un valor CSS válido: default, move, pointer, crosshair, etc.
