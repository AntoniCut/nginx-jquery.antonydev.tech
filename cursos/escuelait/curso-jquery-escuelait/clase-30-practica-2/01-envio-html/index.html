Fase 1

Hacer un plugin que convierta un formulario normal en un formulario Ajax. Simplemente llamamos al plugin sobre el formulario y, cuando se haga el submit, que se envíe por Ajax en vez de enviarse por el método común.

  1. En algún lugar aparece el típico mensaje de carga mientras se espera la respuesta del servidor.
  2. Mientras se envía el formulario se desactiva el botón de submit, para que no se vuelva a enviar hasta recibir el resultado.

En esta página el plugin escribe la respuesta de texto en el mensaje. El PHP responde «Todo correcto».
