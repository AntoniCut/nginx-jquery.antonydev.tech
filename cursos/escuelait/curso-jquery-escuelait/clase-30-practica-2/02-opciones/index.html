Fase 2

Como segunda fase hacemos lo mismo que la fase 1, pero le agregamos validación. El plugin convierte un formulario normal en un formulario Ajax con validación. El formulario se envía al servidor, que devuelve un JSON con un formato como este:

{ "valido": true }

Si el formulario no era válido:

{
    "valido": false,
    "errores": "<ul><li>No has indicado el nombre</li><li>No has indicado el email</li></ul>"
}

Las validaciones dan igual. La idea es procesar ese JSON en el cliente con jQuery.

Al invocarlo, el plugin puede recibir url, capaMensaje y metodo. url es la dirección de envío. capaMensaje es la capa del mensaje de carga y de la respuesta, válida o con errores. Por defecto url y capaMensaje valen false y metodo vale post. Si url es false, se usa el action del formulario. Si capaMensaje es false, el plugin crea un elemento, lo inserta dentro del formulario y muestra ahí los mensajes. metodo solo puede ser post o get; cualquier otro valor queda en post.

En esta página la url sale del action. La capa de mensaje y el método se pasan como opciones. Si falta un campo, el mensaje lista el fallo.
